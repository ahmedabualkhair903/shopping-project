# LUXORA

LUXORA is a responsive storefront and product-management demo built with
Next.js 16, React 19, TypeScript, and Tailwind CSS. Its catalog, cart, wishlist,
reviews, accounts, and orders are stored in the browser; this project does not
provide a backend, secure authentication, or real payment processing.

## Getting started

Install the locked dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to browse the storefront.
Catalog and account changes are local to the current browser.
